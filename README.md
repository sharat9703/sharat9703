🚀 **About Me**
Backend engineer with **2+ years** building secure, high-volume **Node.js / TypeScript** services for mission-critical **BFSI & FinTech** platforms, including **SWIFT / ISO 20022** payment messaging.
I own features end to end, from design and REST/microservice implementation to deployment and production support. B.Tech CSE, **IIIT Trichy**.

- 🏦 Software Development Engineer @ **Credence Analytics**, treasury & capital-markets products
- 🔭 Currently building **MCP servers** and **Claude Code** skills/hooks that automate developer workflows
- 🌱 Exploring **Kafka, NestJS, Kubernetes, PostgreSQL**

📌 **Highlights**
- ⚡ **Event-driven sync:** queue-backed schedulers across 6 services (2 legacy monoliths + 4 Node.js apps), sustaining ~10K transactions/day with zero data loss
- 🔗 **Enterprise integrations:** 7+ third-party integrations: Video KYC, APIGEE OTP/SMS auth, GST E-Invoice (IRN), Razorpay refunds
- 💱 **Legacy modernization:** migrated forex & SWIFT credit-transfer modules (MT199, ISO 20022 pacs.008) to Node.js REST APIs across 3 production apps
- 🔐 **Security:** end-to-end AES/RSA encryption layer, plus a watcher framework enforcing payload encryption on 60+ endpoints
- 🛠️ **Production ownership:** resolved 100+ production defects with RCA, cut repeat tickets by 20%+, and brought Oracle queries from ~2s to under 1s
- 🤖 **Dev tooling:** automated release-patch prep from over an hour to ~5 minutes
